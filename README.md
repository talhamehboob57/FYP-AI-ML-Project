# GroundCheck

**A Retrieval-Augmented QA System with Claim-Level Verification and Source Citations**

## Overview

GroundCheck is a Final Year Project (FYP) focused on improving the reliability of answers generated by Retrieval-Augmented Generation (RAG) systems.

The proposed system will allow users to upload text-based PDF documents and ask questions about their contents. It will retrieve relevant passages, generate answers using a language model, and verify individual answer claims against the retrieved evidence using a pretrained Natural Language Inference (NLI) model.

The system aims to highlight claims that are contradicted by, or not sufficiently supported by, the retrieved evidence and provide page-level source citations to help users verify the answers.

## Key Objectives

- Develop a document-based question-answering system using RAG.
- Provide source citations linking answers to relevant PDF pages.
- Verify answer claims against retrieved document passages.
- Highlight claims that lack sufficient supporting evidence.
- Evaluate the effectiveness and response-time overhead of claim-level verification.

## Proposed Technology Stack

- **Frontend:** React
- **Backend:** Python, FastAPI
- **Vector Database:** PostgreSQL with pgvector
- **Embeddings and Verification:** Sentence Transformers and a pretrained NLI model
- **Language Model:** Hosted LLM API
- **Deployment:** Docker
- **Version Control:** Git and GitHub

## Project Scope

The initial scope is limited to English, text-based PDF documents. Scanned PDFs requiring OCR, image and table extraction, model fine-tuning, and multilingual support are outside the initial scope.
